UTAK Mall Bridge

Which mall is this laptop for?

The bridge sends this store's sales files to the mall. Pick carefully: once set, only UTAK support can change it.

Only UTAK support can change this later. If this laptop is for a different mall, go back now.

    Paste the store's setup code

    In the UTAK Admin: Mall Config → this store → ACC → Generate Bridge Key. Copy the code it shows, then paste it here.

    Choose the ACC folder

    The folder the mall collects from: C:\ACC on this laptop, or the shared folder the mall's IT gave you (for example \\server\share). The bridge checks it can save files there.

    Point the POS tablets at this laptop

    On each POS: Ayala settings → Bridge IP. Enter this address. If this laptop has more than one network, pick the store Wi-Fi or LAN one.
